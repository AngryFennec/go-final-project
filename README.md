# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Для запуска тестов нужно запустить сервер ```go run main.go```, и затем прогнать тесты ```go test ./tests```

Директория `web` содержит файлы фронтенда.

# Функционал

Реализованы отображение списка задач, добавление новой задачи, редактирование, удаление и выполнение задачи.
